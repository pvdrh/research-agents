# HTML Report Render

## Khi nào dùng
- Format đầu ra là `.html` (cả SINGLE và BATCH).

## Input
```json
{
  "mode": "single | batch",
  "state": { ... }
}
```

`state` cho SINGLE chứa: `requirements`, `tech_stack`, `architecture`, `review_log`.
`state` cho BATCH chứa: `project`, `capabilities[]`, `cases[]`, `overall`, `panel`, `case_adjustments`, `review_log`.

## Quy trình chung
1. Gọi `design-token-loader` để lấy tokens (cache trong cùng pipeline run).
2. Sinh `<style>` CSS frozen từ tokens.
3. Sinh body theo mode (SINGLE article / BATCH SPA).
4. Inject Mermaid CDN cho client-side render.
5. Trả HTML string đầy đủ.

### 🚨 KHÔNG render Python list/dict repr — luôn convert sang HTML list

**Lỗi production đã thấy:** Writer dump trực tiếp `api[]`, `kpi[]`, `principles[]`, `data_in/out`, `key_components[]` vào `<pre>` qua `str(list)` → ra `['item1', 'item2', ...]` xấu khó đọc.

**Quy tắc BẮT BUỘC:**
- BẤT KỲ field nào là list/array → render thành `<ul><li>...</li></ul>`, KHÔNG bao giờ `<pre>{python_repr}</pre>`.
- BẤT KỲ field nào là dict → render thành definition list `<dl>` hoặc bảng key-value, KHÔNG `<pre>{repr}</pre>`.
- `<pre>` CHỈ dùng cho: code block, JSON đã format, Mermaid raw (debug).

Helper template (Python f-string):
```python
def render_list(items, font_size=13):
    if not items: return ''
    lis = ''.join(f'<li style="margin-bottom:6px">{html.escape(str(it))}</li>' for it in items)
    return f'<ul style="margin:0;padding-left:20px;line-height:1.65;color:#1a1a1a;font-size:{font_size}px">{lis}</ul>'

def render_dict(d, font_size=13):
    if not d: return ''
    rows = ''.join(f'<tr><td style="padding:4px 8px;font-weight:600;color:#5645d4">{html.escape(str(k))}</td><td style="padding:4px 8px;color:#1a1a1a">{html.escape(str(v))}</td></tr>' for k,v in d.items())
    return f'<table style="border-collapse:collapse;font-size:{font_size}px">{rows}</table>'
```

### Sequence diagram arrow — KHÔNG được ẩn

🚨 Lỗi cũ: CSS `.mermaid svg .messageText { stroke:none !important; }` đặt cho TEXT bị áp lan sang `<line>` / `<path>` arrow nếu selector quá rộng. Defense layer CSS phải nhắm CHỈ vào text element, không động vào line.

Quy tắc CSS arrow (BẮT BUỘC):
```css
/* TEXT only — không animation lan sang line/path */
.mermaid svg text.messageText,
.mermaid svg .messageText > tspan { fill:#1a1a1a !important; stroke:none !important; }

/* LINE/PATH của sequence message — KHÔNG override stroke:none */
.mermaid svg .messageLine0, .mermaid svg .messageLine1 { stroke:#5d5b54 !important; stroke-width:1.5 !important; fill:none !important; }
.mermaid svg path.messageLine0, .mermaid svg path.messageLine1 { stroke:#5d5b54 !important; stroke-width:1.5 !important; fill:none !important; }

/* ARROW HEAD marker phải có fill (không phải stroke:none) */
.mermaid svg marker path,
.mermaid svg defs marker path { fill:#5d5b54 !important; stroke:none !important; }
.mermaid svg #arrowhead path,
.mermaid svg [id^="arrowhead"] path { fill:#5d5b54 !important; }

/* Sequence actor lines (vertical lifelines) phải visible */
.mermaid svg line.actor-line { stroke:#5d5b54 !important; stroke-width:1 !important; }
.mermaid svg .actor-man line, .mermaid svg .actor-man circle { stroke:#5d5b54 !important; fill:#ede9fe !important; }
```

Anti-pattern (đã gây mất arrow):
```css
/* ❌ SAI — selector quá rộng, ẩn cả arrow line/path */
.mermaid svg .messageText { stroke:none !important; }  /* không phân biệt text vs line */
.mermaid svg path { stroke:none !important; }          /* ẩn TẤT CẢ path bao gồm arrow */
.mermaid svg line { display:none; }                    /* ẩn cả lifeline */
```

### Mermaid init & render lifecycle (BẮT BUỘC theo pattern này cho SPA)

**🚨 Vấn đề thường gặp:** Trong SPA BATCH, mỗi page là 1 `<div class="page">` với `display:none`. Mermaid v10+ với `startOnLoad:true` chỉ scan DOM 1 lần lúc load — block trong page ẩn KHÔNG render. Khi user nhấn nav để show page, block hiện ra nhưng vẫn là text thô → user thấy "không có diagram nào".

**Quy tắc BẮT BUỘC:**
1. `mermaid.initialize({startOnLoad:false, ...})` — KHÔNG dùng `startOnLoad:true` cho SPA.
2. Ngay khi DOMContentLoaded, snapshot raw source mỗi block: `el.setAttribute('data-mermaid-src', el.textContent.trim())` để khi rerender không bị mất source.
3. Hàm `showPage(id)` / `go(id)` PHẢI gọi `renderMermaidIn(pageEl)` sau khi swap content / set active.
4. `renderMermaidIn` lazy: skip nếu block đã `data-rendered=1`; nếu chưa, gọi `mermaid.render()` và inject SVG.
5. Render lỗi không được vỡ pipeline: bọc try/catch, in `<pre>` đỏ với message + raw source cho dev debug.
6. Initial render: chạy `renderMermaidIn(activePage)` khi `DOMContentLoaded`.

**🎨 Theme variables BẮT BUỘC đầy đủ (lỗi production: chữ trắng trên nền sáng, label vô hình):**

Lỗi điển hình: Mermaid `theme:'base'` mặc định set một số biến thành trắng/đen tùy ngữ cảnh, dẫn tới:
- Edge label trong sequence diagram nền trong suốt → đè lên line gạch → khó đọc.
- Note (`Note over X,Y`) nền vàng nhạt + chữ vàng/trắng → vô hình.
- Actor name (sequence) chữ trắng trên nền nhạt → vô hình.
- Khi Architect viết `classDef foo fill:#f0eefb,color:#fff` → chữ trắng trên nền tím nhạt → vô hình.

**🎯 classDef luminance auto-fix (Writer post-process trước Write file):**

Nếu Architect viết classDef có `color:#fff` trên fill light luminance, Writer phải ép `color` thành `#1a1a1a` (và ngược lại). Đơn giản nhất: sau khi build HTML string, dùng regex rewrite:

```python
import re
def rewrite_classdef(match):
    line = match.group(0)
    fillm = re.search(r'fill:(#[0-9a-fA-F]{3,6})', line)
    if not fillm: return line
    h = fillm.group(1)[1:]
    if len(h)==3: h = ''.join(c*2 for c in h)
    try: r,g,b = int(h[0:2],16), int(h[2:4],16), int(h[4:6],16)
    except: return line
    luma = 0.299*r + 0.587*g + 0.114*b
    if luma > 160:    # light bg → dark text
        line = re.sub(r'color:#(fff|ffffff|FFF|FFFFFF)\b', 'color:#1a1a1a', line)
        line = re.sub(r'color:white\b', 'color:#1a1a1a', line)
        if 'color:' not in line:
            line = re.sub(r'(fill:#[0-9a-fA-F]{3,6})', r'\1,color:#1a1a1a', line, 1)
    else:             # dark bg → light text
        line = re.sub(r'color:#(000|000000|1a1a1a|37352f)\b', 'color:#ffffff', line)
        if 'color:' not in line:
            line = re.sub(r'(fill:#[0-9a-fA-F]{3,6})', r'\1,color:#ffffff', line, 1)
    return line

html = re.sub(r'classDef\s+\w+\s+[^\n<]+', rewrite_classdef, html)
```
